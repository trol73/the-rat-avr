# The Rat AVR

**The Rat** (The Rat assembly tool) — это кросс-архитектурный компилятор системного программирования, написанный на Kotlin. Компилирует язык, похожий на C, в машинный код для микроконтроллеров и классических 8-битных процессоров.

**Версия:** 0.3 | **Платформы:** JVM, Linux, macOS, Windows

See description here: https://trolsoft.ru/en/soft/the-rat-avr 

Описание на русском: https://trolsoft.ru/ru/soft/the-rat-avr

## 🎯 Назначение

The RAT предназначен для разработки встроенного ПО (firmware) для микроконтроллеров и работы с классическими 8-битными архитектурами. Язык предоставляет низкоуровневый доступ к аппаратным ресурсам, сохраняя при этом высокоуровневую структуру, знакомую по языкам C/C++.

### Поддерживаемые архитектуры

| Архитектура | Процессоры | Особенности |
|-------------|-----------|-------------|
| **AVR** | ATmega8, ATmega128 и другие | 32 регистра, регистры указателей X/Y/Z, вектора прерываний |
| **Intel 8080/8085** | 8080, 8085 | Регистры A/B/C/D/E/H/L, регистровые пары, встроенный декомпилятор |

## ✨ Возможности

### Язык программирования
- Синтаксис, похожий на C (процедуры, переменные, структуры, циклы)
- Поддержка типов: `byte`, `word`, `dword`, `qword`, `ptr`, `prgptr`
- Стилизованные типы: `uint8_t`, `uint16_t`, `int8_t`, `char` и др.
- Объявление структур и объединений (`struct`, `union`)
- Массивы и инициализация данных

### Низкоуровневый доступ
- Прямая работа с регистрами процессора (`r0`–`r31` для AVR, `A`–`L` для 8085)
- Объявление пинов портов (`pin pinName = C1`)
- Регистровые псевдонимы (`use r16 as tmp`)
- Абсолютное размещение переменных в памяти (`absolute 0x100`)

### Управление потоком
- `if` / `else` — условные операторы
- `loop` — циклы со счётчиком (регистр, регистровая пара, инициализация)
- `do ... while` — цикл с постусловием
- `goto` — безусловный переход
- `break` / `continue` — управление циклами

### Прерывания (AVR)
- Блок `vectors` для определения обработчиков прерываний
- Поддержка всех векторов: `RESET`, `INT0`, `INT1`, `TIMER2_COMP` и др.

### Препроцессор
- `#define` — макросы
- `#ifdef` / `#ifndef` / `#else` / `#elif` / `#endif` — условная компиляция
- `#include` — включение файлов (поиск по путям из `-I`)
- `#error` — ошибка компиляции с сообщением (останавливает компиляцию)
- `#warning` — предупреждение компиляции (продолжает компиляцию)
- Встроенные макросы:
  - `__LINE__` — номер текущей строки
  - `__FILE__` — имя текущего файла
  - `__DATE__` — дата компиляции (формат: `Mon DD YYYY`)
  - `__TIME__` — время компиляции (формат: `HH:MM:SS`)
  - `__COUNTER__` — инкрементальный счётчик

### Дополнительные возможности
- `saveregs` — автоматическое сохранение/восстановление регистров
- `inline` — встроенные процедуры
- `extern` — внешние переменные и процедуры
- **Процедуры с результатами** — возврат значений через регистры
- **Вызов функций с назначением результатов** — `rcall func() -> (name: reg, ...)`
- **Именованные параметры вызова** — `rcall func(arg1: val1, arg2: val2)`
- Встроенная функция `bitmask()` — генерация битовых масок (биты 0–15)
- Директивы: `$org` (адрес), `$output` (имя файла), `$encoding` (кодировка), `$pad_to` (выравнивание)

### Форматы вывода
- **Intel HEX** (.hex) — стандартный формат для прошивок
- **GCC-совместимый ассемблер** (.S) — для avr-gcc
- **Бинарный файл** (.bin)
- **Листинг** (.lst) — с исходным кодом и адресами
- **Собственные форматы**: .rkr, .gam (для Intel 8080/8085)

### Декомпилятор (Intel 8080/8085)
- Встроенный дизассемблер машинного кода
- Поддержка исторических форматов (RK-86, ДВК и др.)

## 📝 Синтаксис языка

### Объявление программы

```rat
#define CPU "atmega8"

var sUartRxBp: byte

proc main() {
    sUartRxBp = ZL
}
```

### Типы данных

```rat
var b: byte          // 1 байт (0..255)
var w: word          // 2 байта (0..65535)
var dw: dword        // 4 байта
var qw: qword        // 8 байт
var p: ptr           // указатель
var pp: prgptr       // указатель на память программ (AVR)
```

### Процедуры

```rat
// Обычная процедура
proc main() {
    var x: byte
    x = 10
    return
}

// Встроенная процедура
inline proc nop2() {
    nop
    nop
}

// Процедура с аргументами-регистрами
inline proc outPort(val: r24) {
    PORTD = val
}

// Именованные аргументы
inline proc outPorts(val1: r24, val2: r25) {
    PORTD = val1
    PORTC = val2
}

// Процедура с результатами (возвращает значения через регистры)
proc readWord() -> (lo: r24, hi: r25) {
    lo = mem[Z]
    hi = mem[Z+1]
    ret
}
```

### Переменные и массивы

```rat
var x: byte
var buf: byte[10]            // массив
var ms: my_struct_t[5]       // массив структур
var addr: word absolute 0x100  // абсолютное размещение
```

### Вызов процедур


## 🛠 Компиляция и запуск

### Технические требования
- **JDK 17+** (для JVM-версии)
- **Gradle 9.3.0** (для сборки из исходников)
- **Kotlin 2.3.21** (KMP)

### Из исходного кода

```bash
./gradlew build
```

### Запуск компилятора

```bash
ratc [опции] <файл_источника> [<файл_вывода>]
```

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `-D<macro>=<value>` | Определить макрос |
| `-I<dir>` | Путь поиска включаемых файлов (`#include`) |
| `-dev=<path>` | Путь к файлам устройств (AVR) |
| `-enc=<path>` | Путь к файлам кодировок |
| `-arch=avr\|8080\|8085` | Архитектура процессора |
| `-gcc` | Вывод в формате GCC-ассемблера (AVR) |
| `-list` | Генерация листинга |
| `-help` | Показать справку |

### Пример

```bash
ratc -arch=avr -gcc -DDEBUG=1 main.art output.S
```

## 📖 Пример программы (AVR)

```rat
#define CPU "atmega8"
#define F_CPU 1000000

use r16 as tmp
use r17 as second

pin ledPin = PB5
pin keyPin = D2

var counter: word
var flag: byte

inline proc delay() {
    var i: word
    loop (i = 50000) {
        nop
    }
}

inline proc blinkLed() {
    PORTB->5 = ~PORTB->5
    delay
}

proc main() {
    DDRB = 0xFF
    DDRD = 0xFF
    counter = 0
    flag = 0

    loop (counter < 100) {
        if (!keyPin->pin) {
            delay
            if (!keyPin->pin) {
                blinkLed
                counter++
                while (!keyPin->pin) {
                    nop
                }
            }
        }
    }

    return
}

vectors {
    RESET:
        rjmp main
    TIMER2_COMP:
        PORTB = r20
}
```
